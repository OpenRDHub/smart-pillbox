# Smart Medication Pillbox · 便携智能服药管理药盒

> 「罕见·无界」黑客松赛题 · 项目3：发作性睡病 + 智能药盒
> 由 [OpenRD 罕见病开源社区（Khub）](https://github.com/OpenRDHub)发起 · 患者共创 · 一个赛题 = 一个长期开源项目

为规律服药群体打造便携智能服药管理药盒。

## 🧭 背景与真实处境

发作性睡病等慢性病患者需要长期、多药物、多时段规律服药。**漏服、重复服药、提醒弱、记录难**，是多药物多时段场景中的真实困扰——不仅影响疾病控制，某些药物漏服或重复服用还可能带来安全风险；而现有药盒提醒方式单一（声音/文字），在入睡、嘈杂、外出等场景下容易失效，家属也难以及时知情。

## 🎯 挑战方向

- **强震动提醒**：在睡眠、嘈杂等场景下确保提醒可感知
- **服药间隔追溯**：记录每次开盒/取药时间，防止重复服药
- **防摔密封收纳**：兼顾便携性与药品保存
- **家属异常事件推送**：漏服、超时未服等异常自动通知家属

## 📌 项目状态

赛题已开放，详细需求资料与患者访谈将陆续沉淀到社区知识库（本仓库同步更新）。

**可参考的切入路径**（欢迎讨论）：

- 低功耗嵌入式主控 + 分格药仓 + 仓位传感器（开盒/取药检测）
- 蓝牙 / Wi-Fi 联动手机 App：服药计划、记录看板、家属推送
- 结构设计面向 3D 打印可自制，降低患者获取成本
