## 🧭 疾病背景：发作性睡病

发作性睡病（Narcolepsy）是一种以睡眠-清醒节律调节障碍为核心的慢性中枢神经系统疾病：大脑中维持清醒的神经递质（下丘脑分泌素 / Orexin）缺乏或功能不足，睡眠与清醒的"边界"变得不稳定。

- **流行病学**：人群患病率约 1/2000，中国患者估算约 70 万；10–20 岁学龄期起病，正值升学关键期
- **确诊难**：从症状出现到确诊平均延迟常达数年，期间常被误认为"懒、厌学、装病、癫痫、抑郁"
- **典型"五联症"**：日间过度思睡（必备，"突然断电"般秒睡）、猝倒（大笑等情绪诱发的"笑软"，1 型标志）、睡眠瘫痪（"鬼压床"）、入睡前幻觉、夜间睡眠紊乱
- **治疗**：白天促清醒药（莫达非尼、哌甲酯等）+ 抗猝倒药（文拉法辛等）+ 夜间 γ-羟丁酸钠——**白天多次服药、夜里还要起来服第二次药**，需终身规律用药，按时按量服药本身就是疗效与安全的核心（医学依据：《中国发作性睡病诊断与治疗指南（2022 版）》）

## ❓ 为什么普通药盒不够用

普通定时药盒和手机闹钟是为"记得吃药但容易忘"的人设计的；发作性睡病患者面对的是另一组问题——**患者可能正处于睡眠中根本听不到响铃；醒来后又可能意识模糊、记忆断片，无法确认自己吃没吃**；夜间服药、猝倒发作、多药联用、家属不在身边等情况进一步放大风险。

**患者组织调研归纳的 8 大痛点与对应设计要求**：

| # | 患者痛点 | 需要的设计 |
|---|---|---|
| 1 | 白天随时"断电"，闹钟响了也醒不来 | 强震动 + 声音 + 闪光多通道提醒，持续提醒至实际取药才停止；超时未取逐级升级，最终通知家属 |
| 2 | 夜间需醒来服第二次药（如 γ-羟丁酸钠） | 贴身强震动弱声、夜光指示、摸黑可操作，不影响同住家人 |
| 3 | 嗜睡中醒来记忆断片，"我到底吃药没有？" | 盒盖开合自动记录 + 盒体屏幕常显"上次服药时间"；未到安全间隔物理锁定药格，防止重复取药 |
| 4 | 多种药物、多个时段，靠脑子记不住 | 多药格分区 + 按天/按周设置方案，每格可标注药名剂量，支持低药量预警 |
| 5 | 猝倒发作时手部无力，普通药盒抠不开、药粒易洒 | 单手可开、无需精细捏取，带阻尼防洒，夜光便携口袋大小 |
| 6 | 家属无法确认是否按时服药 | 家属端 App 远程查看服药状态，漏服超时自动推送，一键电话联系 |
| 7 | 病耻感强，不愿在学校/公司暴露病情 | 外观像普通数码配件，可静音纯震动，屏幕隐私模式（不显示药名） |
| 8 | 小睡睡过点，醒来已错过服药窗口 | 小睡联动：检测到久卧起身（小睡结束）重新触发提醒，把错过的药接上 |

**一句话总结**：把睡着的人叫醒（防漏服）+ 让醒了的人确认自己吃没吃（防重复）+ 家属后台知情。这两个核心能力"拆开都有人做，合二为一、且专为发作性睡病设计的，目前市面上没有"。

## 📊 现有产品与市场空白（患者组织已完成调研，2026-09）

**国内四款代表产品**：

| 产品 | 参考价 | 优势 | 关键差距 |
|---|---|---|---|
| A. 定时振动药盒（白牌/e-pill 同款） | ¥26–39 | 有震动、口袋大小、便宜 | 无记录、无屏幕、无联动、医疗塑料外观 |
| B. 药准时 Memo Box | 百元级 | 开合记录 + 重复取药红灯告警 + 家人共享 | 仅蜂鸣无震动、盒体无屏幕、2017 年老产品 |
| C. LE-CARE 优乐合（2024） | ¥308–389 | 最完整：小程序配置、家属共享、漏服推送（4G 版） | 无震动、无屏幕、家庭桌面大药仓不便携 |
| D. HiPee 智能药盒 | ¥105–149 | 便携便宜、红灯防重复、微信同步家人 | 无强震动（触觉强度存疑）、无屏幕、无锁定 |

**国外成熟单品**：e-pill TimeCap/TimerCap 计时瓶盖（US$24–30）——瓶盖 LCD 常显"上次开盖时间"，把防重复解决得极简可靠，是全球验证最成功的单品；但没有闹钟和震动、依赖标准药瓶、需海淘。海外用户同样是"一手计时瓶盖、一手振动药盒"，**没有把两件事做进一个设备**。

**调研结论**：机会不在于再造一个闹钟，而在于把已被验证的两项核心能力（**强震动提醒 + 开盖计时显示**）合二为一，并补齐家属端与疾病专属交互。现有产品全部默认使用者是"清醒、听得见、愿意拿手机"的老人，而非随时可能秒睡的发作性睡病患者。

## 🎯 挑战方向

- 多通道强提醒（强震动为主）+ 逐级升级直至家属通知
- 开合自动记录 + 盒体常显屏幕 + 安全间隔物理锁定
- 夜间二次服药专属方案与猝倒友好结构（单手开、防洒）
- 小睡联动、隐私外观与隐私模式、家属端 App
