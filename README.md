# Narcolepsy Smart Pillbox · 发作性睡病专用智能药盒

> 「罕见·无界」黑客松 · 赛题3 · 发作性睡病 + 智能药盒
> 依据《发作性睡病专用智能药盒 产品需求书 V1.0》（2026-10-01）编写 · 患者组织「觉主家」共建 · [OpenRD 罕见病开源社区（Khub）](https://github.com/OpenRDHub)发起

一款真正「懂发作性睡病」的智能药盒——**叫得醒 + 记得清 + 防重复 + 家属知 + 不暴露**。要同时解决两件事：**把睡着的人叫醒（防漏服）**和**让醒了的人确认自己吃没吃（防重复）**，并让家属在后台知情。这两个核心能力「拆开都有人做，合二为一、且专为发作性睡病设计的，目前市面上没有」。

## 🧭 一、疾病背景

发作性睡病（Narcolepsy）是以睡眠-清醒节律调节障碍为核心的慢性中枢神经系统疾病：维持清醒的神经递质（下丘脑分泌素/Orexin）缺乏或功能不足，睡眠与清醒的「边界」不稳定。**它不是「懒」「贪睡」或「睡得晚」。**

| 指标 | 数值 |
|---|---|
| 人群患病率 | 约 1/2000（并不罕见） |
| 中国患者估算 | 约 70 万（确诊和治疗比例很低） |
| 起病高峰 | 10–20 岁学龄期（正值升学关键期） |
| 症状出现到确诊 | 常达数年（常被误认为懒、厌学、装病、癫痫、抑郁） |

**典型「五联症」**：① 日间过度思睡（必备——「突然断电」般秒睡，可发生在课堂甚至过马路时）；② 猝倒/「笑软」（1 型标志，情绪诱发的短暂肌张力丧失，发作时意识清醒——与癫痫晕厥区分的关键）；③ 睡眠瘫痪（「鬼压床」）；④ 入睡前幻觉；⑤ 夜间睡眠紊乱。

**治疗与用药特点**：白天促清醒药（莫达非尼、哌甲酯等，通常是早上和中午）+ 抗猝倒药（文拉法辛等）；夜间 γ-羟丁酸钠需二次服用（**国内目前没有这款药物，仅极少数有国外药源的患者使用——设计时可根据实际情况取舍**）。疾病慢性、需终身规律用药，按时按量服药本身就是疗效与安全的核心。

## ❓ 二、为什么普通药盒会失效

普通定时药盒和手机闹钟是为「记得吃药但容易忘」的人设计的，逻辑是「到点响铃→人听到→去吃药」。但发作性睡病患者：**可能正处于睡眠中根本听不到响铃；醒来后又可能意识模糊、记忆断片，无法确认自己吃没吃**；夜间服药、猝倒发作、多药联用、家属不在身边等情况进一步放大风险。

## 🛠 三、核心功能需求（痛点→设计映射）

| # | 患者痛点 | 需要的设计 |
|---|---|---|
| 1 | 白天随时「断电」，闹钟响了也醒不来 | 强震动+声音+闪光多通道提醒，**持续提醒至实际取药才停止**；超时未取逐级升级，最终通知家属 |
| 2 | 夜间需醒来服第二次药（仅极少数患者，赛手自行选择是否重视） | 贴身强震动弱声、夜光指示、摸黑可操作，不影响同住家人 |
| 3 | 嗜睡中醒来记忆断片，「我到底吃药没有？」 | 盒盖开合自动记录+盒体屏幕常显「上次服药时间」，**无需任何操作拿起来看一眼就知道**；未到安全间隔**物理锁定**药格 |
| 4 | 多种药物多个时段，靠脑子记不住 | 多药格分区+按天/按周设置方案，每格标注药名剂量时间，低药量预警 |
| 5 | 猝倒发作时手部无力，普通药盒抠不开、药粒全洒 | 单手可开、无需精细捏取、带阻尼防洒、夜光、口袋大小 |
| 6 | 家属无法确认是否按时服药 | 家属端 App 远程查看服药状态，漏服超时自动推送，一键电话联系 |
| 7 | 病耻感强，不愿在学校/公司暴露病情 | 外观像普通数码配件、可静音纯震动、屏幕隐私模式（不显示药名） |
| 8 | 小睡睡过点，醒来已错过服药窗口 | 小睡联动：检测到久卧起身（小睡结束）重新触发提醒，把错过的药接上 |

**非功能需求**：提醒必须持续至实际取药（防重复必须是物理锁定而非软提示）；零操作（意识模糊下「看一眼就知道」，不依赖掏手机）；夜间不打扰家人；隐私与尊严；便携（可带去学校公司）；**适配国内装药习惯**（盒装/板装/分装药，不依赖标准处方药瓶）。

## 📊 四、竞品格局与市场空档

**国内四款代表产品对照**（患者核心需求 × 产品能力）：

| 患者核心需求 | A. 定时振动药盒（¥26–39） | B. 药准时 Memo Box（百元级） | C. LE-CARE 优乐合（¥308–389） | D. HiPee（¥105–149） |
|---|---|---|---|---|
| 强震动叫醒睡着的人 | ✓ 有 | × 仅蜂鸣 | × 蜂鸣+灯光 | △ 强度待实测 |
| 盒体屏幕常显上次服药时间 | × 无屏幕 | × 靠 App | × 靠小程序 | × 靠小程序 |
| 开合自动记录 | × | ✓ | △ 仅 4G 版 | ✓ |
| 重复告警/间隔锁定 | × | △ 红灯无锁定 | △ 亮灯无锁定 | △ 红灯无锁定 |
| 家属知情/漏服推送 | × | △ 产品老旧 | ✓ 最完整 | ✓ 微信同步 |
| 便携 | ✓ 口袋大小 | △ | × 家庭大药仓 | ✓ 条状便携 |
| 夜间方案/小睡联动/猝倒友好/隐私模式 | × 全无 | × | × | × |

**国外成熟单品**：e-pill TimeCap/TimerCap 计时瓶盖（US$24–30）——LCD 常显「上次开盖时间」，把防重复解决得极简可靠，是全球验证最成功的单品；但没有闹钟和震动、依赖标准药瓶、需海淘。海外用户同样是「一手瓶盖、一手振动盒」，**没有把两件事做进一个设备**。

**核心结论（被全球市场共同留下的空白）**：「叫醒」与「防重复」被拆在两个设备上，而发作性睡病患者同时需要两者、且要在意识模糊状态下零操作使用；国产新款默认使用者是「清醒、听得见、愿意拿手机」的老人；没有任何一款产品是按这个疾病的场景设计的。**机会在于把强震动提醒 + 开盖计时显示合二为一，补齐家属端与疾病专属交互。**
