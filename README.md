# Smart Medication Pillbox · 便携智能服药管理药盒

> 项目3：发作性睡病 + 智能药盒 —— [OpenRD 罕见病开源社区](https://github.com/OpenRDHub)

为规律服药群体打造便携智能服药管理药盒。

## 真实处境

漏服、重复服药、提醒弱、记录难，是多药物多时段场景中的真实困扰。

## 挑战方向

- 实现强震动提醒
- 服药间隔追溯
- 防摔密封收纳
- 支持家属异常事件推送

## 关键词

`发作性睡病` `规律服药` `智能药盒` `用药记录` `家属提醒`
